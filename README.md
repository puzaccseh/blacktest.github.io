# The Black Onion - Offensive Security Team Website

A modern, responsive website for The Black Onion offensive security team, showcasing their expertise in CTFs, exploit research, and adversary simulation.

## 🚀 Features

- **Modern Design**: Dark theme with cybersecurity aesthetics
- **Responsive Layout**: Optimized for all devices (desktop, tablet, mobile)
- **Interactive Elements**: Animated terminal, smooth scrolling, hover effects
- **Professional Sections**: 
  - Home with animated hero section
  - About Us with service cards
  - Achievements with statistics and timeline
  - Team profiles with social links
  - Contact form with multiple contact methods

## 📁 Project Structure

```
black onion/
├── index.html          # Main HTML file with all sections
├── styles.css          # Complete CSS styling and animations
├── script.js           # JavaScript for interactivity
└── README.md          # Project documentation
```

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with Grid, Flexbox, and animations
- **JavaScript**: Interactive functionality and animations
- **Font Awesome**: Icons for enhanced visual appeal
- **Google Fonts**: Inter font family for modern typography

## 🔧 Customization

### Team Members
Edit the team section in `index.html` to add/modify team members:
```html
<div class="team-card">
    <div class="team-avatar">
        <i class="fas fa-user-ninja"></i>
    </div>
    <h3>Your Name</h3>
    <p class="team-role">Your Role</p>
    <p class="team-bio">Your bio description</p>
    <div class="team-social">
        <!-- Add your social links -->
    </div>
</div>
```

### Contact Information
Update contact details in the contact section:
```html
<div class="contact-details">
    <h4>Email</h4>
    <p>your-email@domain.com</p>
</div>
```

### Achievements
Modify statistics and timeline in the achievements section to reflect your actual accomplishments.
